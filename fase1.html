🎯 Mengapa Fase Ini Krusial?

Banyak pemula langsung lompat ke "hacking tools" seperti Metasploit atau Burp Suite. Hasilnya? Mereka hanya bisa copy-paste tanpa paham apa yang terjadi. Ketika target berbeda sedikit, mereka bingung. Detektif sejati memahami medan sebelum bergerak.

Prinsip: Tools berubah setiap tahun. Fondasi (networking, OS, scripting) bertahan sepanjang karier. Investasi di sini adalah investasi terbaik.

📖 1.1 Networking — Bahasa Sistem

Tanpa paham networking, kamu tidak akan paham apa yang sebenarnya kamu eksploitasi.

Step-by-Step:

  1. Pahami Model OSI & TCP/IP — 7 layer OSI, 4 layer TCP/IP. Fokus: Layer 3 (Network), Layer 4 (Transport), Layer 7 (Application).
  2. Kuasai TCP vs UDP — TCP handshake (SYN, SYN-ACK, ACK), UDP connectionless. Ini dasar port scanning.
  3. Pahami DNS — A record, CNAME, MX, TXT, NS. Subdomain enumeration bergantung pada ini.
  4. Pahami HTTP/HTTPS — Request method (GET, POST, PUT, DELETE), status code (200, 301, 403, 404, 500), header, cookie, session.
  5. Subnetting & Routing — CIDR notation (/24, /16), gateway, NAT. Penting untuk network pentest.
  6. Proxy & VPN — Paham cara traffic di-route, penting untuk anonymization & pivoting.

💡 Contoh Kompleks: Analisis TCP Handshake dengan Python

import socket

def tcp_handshake(target, port):
    """Simulasi TCP 3-way handshake manual."""
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(2)

    print(f"[*] Mencoba handshake ke {target}:{port}")
    try:
        # connect_ex mengembalikan 0 jika sukses (SYN → SYN-ACK → ACK)
        result = s.connect_ex((target, port))
        if result == 0:
            print(f"[+] Port {port} OPEN — handshake berhasil")
            # Kirim HTTP request sederhana untuk lihat banner
            s.send(b"HEAD / HTTP/1.1\r\nHost: " + target.encode() + b"\r\n\r\n")
            banner = s.recv(1024).decode(errors='ignore')
            print(f"[+] Banner:\n{banner[:200]}")
        else:
            print(f"[-] Port {port} closed/filtered (kode: {result})")
    except socket.timeout:
        print(f"[!] Timeout — port {port} mungkin filtered oleh firewall")
    finally:
        s.close()

# Uji ke scanme.nmap.org (legal untuk latihan)
tcp_handshake("scanme.nmap.org", 80)
tcp_handshake("scanme.nmap.org", 22)

Penjelasan: connect_ex() melakukan handshake TCP di balik layar. Kode 0 = sukses, 111 = connection refused (port closed), timeout = filtered. Ini adalah fondasi cara kerja Nmap.

🎯 Target 1.1: Bisa menjelaskan alur request HTTP dari browser ke server (DNS → TCP handshake → HTTP request → response) tanpa melihat catatan.

🐧 1.2 Linux & Terminal — Senjata Detektif

90% tools offensive berjalan di Linux. Kamu harus nyaman tanpa GUI.

Step-by-Step:

  1. Install Linux — VM (VirtualBox/VMware) dengan Kali Linux atau Parrot OS. Alternatif: WSL2 di Windows.
  2. File System Hierarchy — /etc (config), /var (log), /tmp (sementara), /home (user), /root (admin), /usr/bin (executable).
  3. Permission & Ownership — chmod (rwx, numeric 755), chown, umask. Paham SUID/SGID — kunci privilege escalation.
  4. Process Management — ps, top, htop, kill, jobs, bg/fg, nohup.
  5. Text Processing — grep, awk, sed, cut, sort, uniq, jq (JSON). Wajib untuk parsing output tool.
  6. Networking Commands — ifconfig/ip, netstat/ss, curl, wget, nc (netcat), tcpdump.
  7. Bash Scripting — variabel, loop, condition, function, argument parsing. Ini fondasi automation.

💡 Contoh Kompleks: Bash Script — Log Analyzer Detektif

#!/bin/bash
# log-detective.sh — Analisis auth.log untuk deteksi brute force
# Usage: ./log-detective.sh /var/log/auth.log

LOG_FILE="${1:-/var/log/auth.log}"

if [[ ! -f "$LOG_FILE" ]]; then
    echo "[!] File tidak ditemukan: $LOG_FILE"
    exit 1
fi

echo "=========================================="
echo "  PIXEL DETECTIVE — Log Analyzer"
echo "  Target: $LOG_FILE"
echo "=========================================="

# 1. Hitung total failed login
TOTAL_FAILED=$(grep -c "Failed password" "$LOG_FILE")
echo "[*] Total failed login: $TOTAL_FAILED"

# 2. Top 10 IP dengan failed login terbanyak
echo -e "\n[*] Top 10 IP penyerang:"
grep "Failed password" "$LOG_FILE" \
  | awk '{print $(NF-3)}' \
  | sort | uniq -c | sort -rn \
  | head -10

# 3. Deteksi brute force (>= 5 attempt dari IP yang sama)
echo -e "\n[!] IP dengan >= 5 failed attempt (potensi brute force):"
grep "Failed password" "$LOG_FILE" \
  | awk '{print $(NF-3)}' \
  | sort | uniq -c \
  | awk '$1 >= 5 {print "  - " $2 " (" $1 " attempts)"}'

# 4. User yang paling sering dicoba
echo -e "\n[*] User yang paling sering dicoba:"
grep "Failed password" "$LOG_FILE" \
  | awk '{print $(NF-5)}' \
  | sort | uniq -c | sort -rn | head -5

# 5. Login sukses setelah failed (potensi compromise)
echo -e "\n[!] Login sukses (periksa apakah mencurigakan):"
grep "Accepted password" "$LOG_FILE" | tail -5

echo -e "\n[✓] Analisis selesai."

Penjelasan: Script ini menggunakan grep + awk + sort + uniq — kombinasi text processing klasik Linux. $(NF-3) mengambil kolom IP dari format log SSH. Ini adalah skill yang akan kamu pakai terus saat analisis log di pentest.

🎯 Target 1.2: Bisa navigasi Linux tanpa GUI, menulis bash script untuk automasi sederhana, dan paham SUID/SGID untuk privilege escalation.

🐍 1.3 Python — Bahasa Universal Detektif

Python adalah bahasa #1 untuk tooling offensive. Wajib kuasai dasar-dasarnya.

Step-by-Step:

  1. Sintaks Dasar — variabel, tipe data (int, str, list, dict, tuple, set), operator, control flow (if/elif/else, for, while).
  2. Function & Module — def, parameter, return, import module, if __name__ == "__main__".
  3. File I/O — open(), read(), write(), with statement. Penting untuk baca wordlist, log, config.
  4. Library Penting — socket (networking), requests (HTTP), re (regex), subprocess (jalankan command), argparse (CLI), threading (concurrency).
  5. Error Handling — try/except/finally. Tool offensive harus tahan error.
  6. Virtual Environment — venv, pip, requirements.txt. Isolasi dependency per proyek.

💡 Contoh Kompleks: Multi-threaded Port Scanner

#!/usr/bin/env python3
"""
pixel-scan.py — Multi-threaded port scanner ala Pixel Detective
Usage: python3 pixel-scan.py   
"""

import socket
import argparse
import threading
from queue import Queue
from datetime import datetime

# Lock untuk print yang rapi antar thread
print_lock = threading.Lock()
open_ports = []

def scan_port(target, port, timeout=1):
    """Scan satu port. Return (port, banner) jika open."""
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(timeout)
        result = s.connect_ex((target, port))
        if result == 0:
            # Coba ambil banner (service fingerprinting)
            banner = ""
            try:
                s.send(b"HEAD / HTTP/1.0\r\n\r\n")
                banner = s.recv(1024).decode(errors='ignore').strip()[:80]
            except Exception:
                pass
            s.close()
            return (port, banner)
        s.close()
    except Exception:
        pass
    return None

def worker(target, queue):
    """Thread worker: ambil port dari queue, scan, simpan hasil."""
    while not queue.empty():
        port = queue.get()
        result = scan_port(target, port)
        if result:
            port_num, banner = result
            with print_lock:
                open_ports.append(port_num)
                banner_info = f" | {banner}" if banner else ""
                print(f"[+] Port {port_num:5d} OPEN{banner_info}")
        queue.task_done()

def main():
    parser = argparse.ArgumentParser(description="Pixel Detective Port Scanner")
    parser.add_argument("target", help="IP atau hostname target")
    parser.add_argument("start_port", type=int, help="Port awal")
    parser.add_argument("end_port", type=int, help="Port akhir")
    parser.add_argument("-t", "--threads", type=int, default=100,
                        help="Jumlah thread (default: 100)")
    args = parser.parse_args()

    # Resolve hostname ke IP
    try:
        target_ip = socket.gethostbyname(args.target)
    except socket.gaierror:
        print(f"[!] Tidak bisa resolve hostname: {args.target}")
        return

    print("=" * 50)
    print(f"  PIXEL DETECTIVE — Port Scanner")
    print(f"  Target  : {args.target} ({target_ip})")
    print(f"  Range   : {args.start_port}-{args.end_port}")
    print(f"  Threads : {args.threads}")
    print(f"  Waktu   : {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
    print("=" * 50)

    # Isi queue dengan port
    queue = Queue()
    for port in range(args.start_port, args.end_port + 1):
        queue.put(port)

    # Spawn threads
    threads = []
    start_time = datetime.now()
    for _ in range(args.threads):
        t = threading.Thread(target=worker, args=(target_ip, queue))
        t.daemon = True
        t.start()
        threads.append(t)

    # Tunggu semua selesai
    queue.join()

    elapsed = (datetime.now() - start_time).total_seconds()
    print("=" * 50)
    print(f"[✓] Selesai dalam {elapsed:.2f} detik")
    print(f"[✓] Ditemukan {len(open_ports)} port terbuka: {sorted(open_ports)}")

if __name__ == "__main__":
    main()

Penjelasan: Script ini mendemonstrasikan:
• socket untuk koneksi TCP
• threading + Queue untuk concurrency (100x lebih cepat dari sequential)
• argparse untuk CLI yang proper
• print_lock untuk menghindari output berantakan antar thread
• Banner grabbing sederhana untuk fingerprinting service

🎯 Target 1.3: Bisa menulis script Python yang menerima argumen CLI, melakukan koneksi network, dan menangani error dengan baik.
