"Skill tanpa bukti publik adalah rahasia yang tidak bernilai di pasar."

⏱️ Berkelanjutan • 🎯 Target: Siap apply junior pentest / bug bounty

🎯 Mengapa Portfolio?

Di offensive security, bukti praktikal lebih berharga daripada CV. Recruiter ingin melihat: apa yang sudah kamu hack (legal), bagaimana kamu berpikir, dan bagaimana kamu mendokumentasikan.

Prinsip: Persona "Pixel Detective" harus konsisten di semua platform. Bio, logo, tagline, dan kualitas konten harus mencerminkan identitas yang sama.

📁 6.1 Membangun Portfolio

Step-by-Step:

  1. GitHub — Repo terstruktur: pixel-detective-recon, ctf-writeups, custom-tools. README yang jelas.
  2. Blog/Writeup — Medium, GitHub Pages, atau Hashnode. 5+ writeup mendalam.
  3. Twitter/X — Share temuan, tips, screenshot (dengan opsec). Bangun audiens.
  4. LinkedIn — Profil profesional, highlight sertifikasi & proyek.
  5. Personal Website — Opsional, tapi bagus untuk branding. Bisa pakai GitHub Pages.

Step-by-Step Masuk Industri:

  1. Bangun portfolio — GitHub, writeup, blog (Fase 5–6).
  2. Ambil sertifikasi — minimal eJPT/PNPT, target OSCP.
  3. Network — komunitas (Discord, Telegram, meetup), conference (HITB, IDSECCONF).
  4. Apply — LinkedIn, JobStreet, Glints, referral. Fokus pada junior role.
  5. Interview prep — technical (lab walkthrough), behavioral (STAR method).
  6. Freelance/Bug Bounty — bangun reputasi sambil menunggu full-time.
